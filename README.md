# ColdArc-AC
# ⚡ ColdArc-AC  ### Slave PWM Controller for H-Bridge TIG Inverters  (PIC16F886)

Данная прошивка предназначена для управления силовой частью (H-Bridge) аппарата аргонодуговой сварки на переменном токе (AC TIG). Плата выступает в роли ведомого устройства ("Slave"), принимая сигнал включения от основной платы управления ("Master").

## Архитектура
* **МК:** PIC16F886 (Тактовая частота: 8 MHz, Внутренний генератор).
* **Среда разработки:** MPLAB X IDE (компилятор XC8).
* **Драйверы:** Расчет на использование оптических драйверов полумоста с функцией изоляции (например, HCPL-316J или A316J). В коде реализован программный **Dead-time (5 мкс)** для предотвращения сквозных токов.

## Принцип работы и блокировка прерываний
Ключевая особенность прошивки — обеспечение идеальной фазовой стабильности.
1. В режиме простоя работает динамическая индикация на таймере и опрос энкодера по прерыванию.
2. При подаче сигнала `BTN_START = 0` (Мастер разрешает сварку), контроллер **полностью отключает все прерывания (`GIE = 0`)**.
3. Дисплей переводится в статический режим (зажигаются все сегменты "8888"), что сигнализирует о генерации тока.
4. Микроконтроллер переходит в хардкорный цикл генерации AC, рассчитывая ШИМ и тайминги в реальном времени, опираясь исключительно на циклы ядра. 

## Меню и Настройки
Управление осуществляется энкодером (перемещение по значениям) и кнопкой энкодера (переключение пунктов меню). Значения циклически отображаются на 4-разрядном 7-сегментном дисплее (ОА).

| Буква на дисплее | Параметр | Диапазон | Описание |
| :--- | :--- | :--- | :--- |
| **A** | Amperage (Мощность) | 10 - 100 % | Ширина ШИМ импульса внутри полупериода. Определяет силу тока. |
| **F** | Frequency (Частота) | 20 - 200 Гц | Частота переключения полярности. Выше частота — более узкая и сфокусированная дуга. |
| **b** | Balance (Баланс) | 10 - 50 % | Доля времени фазы EP (прямая полярность). Отвечает за разрушение оксидной пленки на алюминии. |
| **U** | Up Slope (Нарастание) | 0 - 50 | Время плавного нарастания ШИМ от 0 до заданного `A`. Умножается на 0.1 сек (до 5.0 сек). |
| **d** | Down Slope (Спад) | 0 - 50 | Время плавного гашения дуги (заварка кратера) после отпускания кнопки. Умножается на 0.1 сек. |
| **H** | Hot Start (Прогрев) | 0 - 100 мс | Однократный импульс постоянного тока (EP) при поджиге для формирования шарика на вольфраме. |

## Формирование ШИМ в AC цикле (Phase/Duty Control)
В отличие от классических инверторов, где ток регулируется первичным источником, данная прошивка реализует регулировку мощности за счет обрезки длительности включенного состояния транзисторов (соотношение ON/OFF) внутри каждого рассчитанного полупериода (EP и EN).
Это позволяет реализовать программный "Софт-старт" (Up slope) и "Заварку кратера" (Down slope) исключительно силами силовой AC-приставки, плавно меняя параметр ШИМ.
